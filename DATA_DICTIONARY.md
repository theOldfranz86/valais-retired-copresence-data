# Public data dictionary

| Path | Content |
|---|---|
| `data/tab_01_analysis_flow.csv` | Analytical sample flow and exclusions |
| `data/tab_02_sample_profile.csv` | Sociodemographic profile by residential group |
| `data/tab_02b_retirement_duration.csv` | Retirement-duration summaries |
| `data/tab_02c_profile_comparisons.csv` | Residential-profile comparison |
| `data/tab_02d_nationality.csv` | Nationality distribution (`Suisse`/`Autre`) |
| `data/tab_03_residential_markers.csv` | Residential and biographical markers |
| `data/tab_04_territory_use.csv` | Territory-use summaries |
| `data/tab_04b_territory_composition.csv` | Composition of territorial practices |
| `data/tab_05_r2_dimension_profile.csv` | R2 item profile across the five dimensions |
| `data/tab_06_group_comparisons.csv` | Fifteen R1–R2 indicator comparisons |
| `data/tab_06a_dimension_global_tests.csv` | Five global dimension tests |
| `data/tab_07*` | Intergroup-relation comparisons and distributions |
| `data/tab_08_profile_outcome_models.csv` | Aggregate model-level results |
| `data/tab_s*.csv` | Supplementary distributions, measurement map and diagnostics |

Percentages labelled `percent_valid` or `pct_valid` use valid responses as the
denominator. Percentages labelled `percent_eligible` or `pct_eligible` use the
full eligible analytical group. Missing, `Sans avis` and unavailable responses
are retained as separate aggregate information where the source output provides
them.
